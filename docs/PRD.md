# PRD — LogLens 本地日志探查桌面工具

## 1. 背景与目标

开发者在排查问题时，经常需要在本地翻查数 GB 级别的日志文件。市面上的文本编辑器（VS Code、Notepad++）在打开几百 MB 以上的日志时普遍卡顿甚至崩溃。本工具旨在提供一个**轻量、快速、不爆内存**的桌面客户端，帮助开发者在本地快速检索与分析海量日志。

## 2. 目标用户

- 后端 / 运维工程师：日常排查线上问题，翻查应用日志
- QA / 测试工程师：从测试日志中定位失败原因

## 3. 核心需求

### 3.1 目录导入与文件列表（P0）

- 导入一个目录，列出其中所有 `.log` / `.txt` 文件
- 每个文件展示：文件名、大小、修改时间、解析出的日志条数
- 点击文件即可打开

### 3.2 大文件支持（P0）

- 支持打开 **2GB** 级别的日志文件
- 打开过程不爆内存、UI 不卡死
- 任意行可被滚动访问（含文件末尾）

### 3.3 检索与过滤（P0）

- 关键字搜索（支持正则表达式、区分大小写）
- 按日志级别过滤（TRACE/DEBUG/INFO/WARN/ERROR/FATAL）
- 按时间范围过滤
- 搜索过程有进度反馈，且可取消
- 结果数量可配置上限，防止海量结果撑爆内存

### 3.4 统计分析视图（P1）

- 日志级别随时间分布（折线 / 面积图）
- 各级别总量统计
- Top N 错误信息聚类（归一化后聚合同类错误）

## 4. 非功能需求

| 需求 | 指标 |
| --- | --- |
| 内存占用 | 2GB 文件打开后主进程 RSS ≤ 300MB |
| 响应性 | 索引 / 搜索 / 统计期间 UI 可交互、可取消 |
| 索引速度 | 2GB 文件 ≤ 30s |
| 搜索速度 | 2GB 全量关键字扫描 ≤ 10s |

## 5. 交付物

1. 桌面客户端（Electron + React/Vue + TypeScript）
2. GitHub / Gitee 公开代码仓库
3. AI 过程文档（PRD、技术设计、问题解决记录、规则与 Skills）
4. 运行交互截图 / 视频 + 内存占用截图

## 6. 验收标准

- [ ] 能导入目录并展示文件元信息与日志条数
- [ ] 2GB 文件可打开、可滚动到末尾、可搜索、可统计
- [ ] 搜索与统计均有进度与取消
- [ ] 统计视图能正确渲染时间序列与错误聚类
- [ ] 内存占用符合非功能指标
